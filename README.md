### Basic poker decision engine that combines probabilistic data with LLM-powered reasoning

**Includes:** 
  - Monte Carlo engine: 3000 simulations per decision
  - AI integration: uses Google Gemini API for contextual betting advice
  - Interactive UI: built with streamlit for real-time configuation

**Requires:**
  - Google Gemini API key in .env

Can be run using the command `streamlit run main.py`
